Проект для курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

Текущая версия — прототип игры **«Найди оттенок»**.

## Что это за игра?

«Найди оттенок» — мини-игра на внимательность к цвету. Вверху экрана показан эталонный круг, а по игровому полю движутся несколько кругов. Один из них совпадает по цвету с эталоном, остальные отличаются по яркости или насыщенности.

## Цель

Пройти все 10 уровней: с каждым уровнем отличия между оттенками становятся меньше, а круги движутся быстрее. С 5-го уровня начинается фаза 2 — круги становятся меньше, их становится больше, и они двигаются ещё быстрее. Одна ошибка — игра заканчивается.

## Как управлять?

- **Мышь** — клик по кругу, который считаешь правильным.
- **ESC** — поставить игру на паузу / снять с паузы.

## Что должен делать игрок?

1. Сравнить цвет эталонного круга с цветами движущихся кругов.
2. Кликнуть по кругу, который совпадает с эталоном.
3. Пройти все 10 уровней: с каждым уровнем отличия между цветами становятся меньше, а круги движутся быстрее.
4. При неверном выборе игра заканчивается — можно начать заново.
## Как запустить?

Нужен Node.js 20.19+.

```bash
npm install        # один раз, установить зависимости
npm run dev        # запустить игру локально
npm run typecheck  # проверка типов
npm run build      # сборка в dist/
npm run preview    # локальный просмотр собранной игры
```

Публикация на GitHub Pages настроена автоматически в `.github/workflows/deploy.yml`.

[Ссылка на игру](https://kuziina.github.io/game/)

## Что уже реализовано?

- эталонный круг и движущиеся круги-кандидаты;
- случайная генерация цвета эталона на каждом уровне;
- 10 уровней: скорость растёт, отличия в оттенках уменьшаются;
- фаза 2 с 5-го уровня: круги меньше, их больше, скорость выше;
- правильный выбор переводит на следующий уровень, неверный — к поражению;
- пауза по ESC с затемнением экрана;
- индикатор прогресса до фазы 2 внизу экрана;
- экран результата («Победа» / «Поражение») с кнопкой «Начать заново».

## Что пока не реализовано?

- очки и таблица рекордов;
- звук и анимации;
- стартовое меню и выбор сложности;
- сбор игровых метрик.
